    How to save a web page in HTML format
    1. Navigate to the web page, right-click on the page and select Save as...
    2. Select or create a new folder to save the file, images, and associated items from the web page.
    3. Enter a file name and select Webpage, Complete (*. htm;*html) for the Save as type.
    4. Click the Save button.

    How do I export code from a website?
    Chrome
    1. Right-click on the page you want to view the source for.
    2. Select View page source. - A window opens showing the source code.
    3. Right-click | select Save As.
    4. Select Save as type: Webpage, HTML Only.
    5. Save the file as a . txt. Example file name: source_code. txt.
